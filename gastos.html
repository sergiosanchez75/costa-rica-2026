Conecta tu hoja de gastos

  • Crea una Google Sheet con las columnas Fecha, Tipo de Gasto, Descripción, Lugar, Importe (los valores de Tipo de Gasto y Lugar deben coincidir con EXPENSE_CATEGORIES / EXPENSE_PLACES en data.py).
  • Archivo → Compartir → Publicar en la Web → elige la hoja → formato CSV → Publicar.
  • Pega ese enlace en EXPENSES_SHEET_CSV_URL (data.py) y ejecuta python generate.py otra vez.

Recuerda

  • Esta contraseña es solo una cortina — cualquiera con conocimientos técnicos podría ver el código fuente y saltársela. No es una protección real.
  • Para cambiarla, edita GASTOS_PASSWORD en data.py y vuelve a ejecutar python generate.py.
